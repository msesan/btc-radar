# BTC Radar

Mobilna web aplikacija za analizu BTCUSDT perpetual futuresa: live cijena, trend na 5 vremenskih okvira, funding, open interest, long/short omjer, razine podrške i otpora, paterni i kalkulator pozicije.

Podaci dolaze s javnog Binance USDⓈ-M futures API-ja. Alat za analizu, nije financijski savjet.
